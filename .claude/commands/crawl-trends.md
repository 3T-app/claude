あなたは「商圏うんちく」アプリのトレンド巡回係です。立地調査の「今はやっているもの」レポートの元データを更新します。

## 対象の業態

`src/lib/constants.ts` の `GENRE_SLUGS` を読み、対象の業態と slug を確認してください。
引数 `$ARGUMENTS` に slug が指定されていればその業態だけ、空なら全業態を巡回します。

## 巡回のしかた

業態ごとに WebSearch（必要なら WebFetch）で、ここ1〜3か月に東京で X（旧Twitter）・Instagram・TikTok を中心に話題になっている商品・メニュー・見せ方を調べます。

- ログインが必要なページや、利用規約で自動取得が禁止されているページを無理に読み込まないこと。X・Instagram 本体ではなく、それらの話題をまとめた公開記事・ニュース・公式発表を情報源にします。
- 具体的な商品名・形・サイズ・価格帯、拡散した理由（写真映え・限定性・食べ歩き・推し活など）、刺さっている客層を押さえます。
- 古い情報はそうと分かるように書きます。確かめられないことは書きません。
- **海外の動きも必ず見ます。** 業態ごとに、韓国・台湾・中国・東南アジア・アメリカなどで流行していて日本に来そうなもの、すでに日本に上陸したもの、訪日客が東京で探しているものを1〜2回検索し、report の最後に「🌏 海外」として2〜3項目（国・都市名つき）を入れます。海外の元の話題が分かる記事を sources に入れます。

## 保存のしかた

業態ごとに `data/trends/<slug>.json` を次の形で書き出します（既存ファイルは上書き）。

```json
{
  "genre": "カフェ・喫茶",
  "report": "・〇〇：説明…\n・△△：説明…",
  "sources": [{ "title": "記事タイトル", "url": "https://..." }],
  "fetchedAt": "2026-10-29T12:00:00.000Z",
  "by": "claude-code"
}
```

- `genre` は `GENRE_SLUGS` のキー（日本語の業態名）と完全に一致させます。
- `report` は日本語の箇条書き5〜8項目。
- `fetchedAt` は現在時刻（ISO 8601）。アプリは3日以内のものを新しい順に使います。

最後に、更新した業態と主なトレンドを一覧で報告してください。
